# 🛒 E-Commerce Website

A full-stack E-Commerce Web Application that provides a simple, secure, and user-friendly online shopping experience. This project includes both frontend and backend functionalities for managing users, products, and carts.

This application allows users to browse products, view product details, register and log in, and add items to their cart. The backend handles REST APIs, authentication, database operations, and business logic, while the frontend provides a responsive and interactive user interface.

✨ FEATURES  
User Features:  
- User registration and login  
- Browse products  
- View product details  
- Add and remove products from cart  
- Responsive design for mobile and desktop  

Backend Features:  
- RESTful APIs  
- Product CRUD operations  
- User authentication  
- Secure data handling  
- Database integration  

🧱 TECHNOLOGY STACK  
Frontend: HTML, CSS, JavaScript  
Backend: Node.js, Express.js  
Database: MongoDB / MySQL (modify based on your implementation)  
Tools: Git, GitHub, REST APIs, JSON  

🚀 INSTALLATION & SETUP  

Clone the repository:  
git clone https://github.com/shalini291/E-Commerce-website.git  
cd E-Commerce-website  

Backend setup:  
cd backend  
npm install  
npm start  

The backend server will run at:  
http://localhost:5000  

Frontend setup:  
Open the index.html file in your browser  
(or deploy using GitHub Pages / Netlify)

🔗 SAMPLE API ENDPOINTS  
GET /api/products – Fetch all products  
GET /api/products/:id – Fetch product by ID  
POST /api/users/register – Register user  
POST /api/users/login – Login user  
POST /api/cart – Add product to cart  
DELETE /api/products/:id – Delete product  

📦 DEPENDENCIES  
Backend: express, dotenv, cors, bcrypt, jsonwebtoken, mongoose / mysql  
Frontend: HTML, CSS, JavaScript  

🧪 HOW TO USE  
1. Start the backend server  
2. Open the frontend in a browser  
3. Register or login  
4. Browse products  
5. Add products to cart  
6. Place orders (if implemented)
